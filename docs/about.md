# About Acai

Acai is a small hybrid language inspired by modern syntax and friendly scripting languages.

- No braces or semicolons.
- Human-readable statements like `show`, `set`, `if`, `repeat`, and `make`.
- Supports functions, classes, imports, and simple IO.

## Why use Acai?
Acai is built to help beginners write clean scripts and create small programs without complex punctuation.
