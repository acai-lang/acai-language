# Bug Reporting

If you find an issue in Acai, please describe:

1. The code you ran.
2. The exact error message.
3. Which file or feature caused the problem.

## Common problems
- `Unexpected statement` means the parser did not understand a keyword.
- Missing `then` after `if` or missing `end` in a block are common syntax mistakes.
