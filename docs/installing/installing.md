# Installing Acai

Acai is designed to be easy to install in a small folder.

## Quick install
1. Download the repository or ZIP.
2. Open the project folder in a terminal.
3. Run `dotnet run -- demo\example.acai` to execute a sample file.

## Recommended setup
- Windows: use PowerShell or cmd.
- Install [.NET SDK 10.0](https://dotnet.microsoft.com) if not already installed.
