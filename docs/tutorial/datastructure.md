# Variables and Data

Acai stores values in simple named variables.

## Creating variables
```acai
set age to 32
set greeting to "Hello"
set total = 12 + 5
```

## Strings and math
- Use `+` to concatenate strings or add numbers.
- `set value = 4 + 3 * 2` evaluates math in natural order.
