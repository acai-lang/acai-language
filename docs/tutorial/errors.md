# Errors and Debugging

Common Acai problems are usually syntax or missing values.

## Common mistakes
- Missing `then` after `if`.
- Missing `end` for a block.
- Using `set` with the wrong assignment form.

## Example
```acai
set x to 1
if x == 1 then
    show "Yes"
end
```

## Troubleshooting
- Check the exact error message.
- Confirm blocks are closed with `end`.
- Use `show` to print variables for debugging.
