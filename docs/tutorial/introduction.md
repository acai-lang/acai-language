# Introduction to Acai

Acai is a small, human-friendly language for writing scripts with minimal punctuation.

## What makes Acai different?
- No braces or semicolons.
- English-like keywords such as `show`, `set`, `if`, and `repeat`.
- Simple imports with `use` and basic class support.
