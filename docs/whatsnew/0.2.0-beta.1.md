# 0.2.0-beta.1 — Beta release notes

Release date: 2026-08-17

This is a beta preview release focused on delivering a safer, cross-platform update experience and preparatory tooling for staged binary updates.

Highlights
- Channel-based fresh installs: use `stable` or `beta` channel to download the appropriate platform installer.
- Safe staged patching: chained patches can be applied in sequence to assemble a final binary without overwriting the running executable.
- Single source of version truth: `metadata/VERSION` is now used to determine the local installation version.
- Platform-aware installers: Windows (`.exe`), macOS (`.pkg`), Linux (`.tar.gz`) are supported for fresh installs.
- Documentation: added `docs/installing/updating.md` with matrix format, paths, and troubleshooting.

Feedback
- This is a beta release. Please test the update flows on each target OS and report issues to the repository's issue tracker.

Thank you for testing this beta release — your feedback helps make upgrades safe and reliable.
