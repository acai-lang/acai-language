# What's New in Acai

Acai is an evolving language with a small, friendly syntax for scripting and learning.

## Latest highlights
- Human-friendly `show`, `set`, `if`, `repeat`, and `for` syntax.
- `make function` and `make class` for defining reusable logic.
- `use` imports other `.acai` files.
- Raw strings with `r"..."` and interpolation with `{}`.
